# reaper-cam: руководство пользователя

reaper-cam — расширение для REAPER, которое записывает видео с веб-камеры
вместе со звуком. Камера становится ещё одной дорожкой проекта: вы ставите её
на запись, как обычную звуковую дорожку, нажимаете Record — и после остановки
на этой дорожке появляется видео-айтем, выровненный по звуку.

Главное:

- **Без отдельной программы.** Видео пишет сам REAPER, в обычном режиме
  записи: с pre-roll, count-in, auto-punch, петлёй, паузой и undo.
- **Синхронно со звуком.** Кадр ложится на то место шкалы, которое звучало в
  наушниках, когда камера его сняла. Ручных сдвигов и калибровки нет.
- **Без потери качества.** Кадры сохраняются в файл такими, какими их прислала
  камера (сжатие MJPEG), без пережатия. Процессор почти не нагружается. Кадры
  камер без MJPEG — встроенной камеры Mac, например, — на Windows и macOS
  сжимаются в JPEG при записи.
- **Запись звука не срывается.** Если камера занята, отключена или пропала во
  время записи, звук пишется как обычно, а на видео — чёрный кадр.

## Коротко о словах

- **Дорожка-камера** — дорожка REAPER, у которой формат записи — «Video
  (camera)». Она записывает видео, а не звук.
- **Arm** (постановка на запись) — красная кнопка записи на дорожке. Дорожка,
  поставленная на запись, записывает при нажатии Record.
- **Айтем** — кусок записи на дорожке. После записи на дорожке-камере
  появляется видео-айтем.
- **Дубль** (take) — одна запись в айтеме. При записи в петле каждый проход
  становится отдельным дублем.
- **MJPEG** — способ, которым камера сама сжимает кадры в JPEG. Его отдают
  почти все USB-камеры; расширение записывает только его.
